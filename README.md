# Dani Detalles — sitio web

## Archivos
- `index.html`: estructura y contenido del sitio.
- `style.css`: estilos, colores, diseño adaptable y animaciones.
- `script.js`: menú, animaciones y catálogos interactivos.
- `assets/img/`: fotografías, logotipo y recursos gráficos utilizados por la página.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (puede llamarse `dani-detalles`).
2. Sube **todo el contenido** de esta carpeta, conservando `assets/img/` y sus archivos.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio y abre la URL que aparece en esa misma sección.

Importante: `index.html`, `style.css` y `script.js` deben quedar en la raíz del repositorio. No subas únicamente el HTML: también se necesita la carpeta `assets`.
